# Michael-Manganel-Portfolio

A responsive, research-forward portfolio for Michael Manganel.

## Preview

Open `index.html` in a browser, or serve this folder locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Personalize

- Replace the project prompts in the Projects section with actual research, coursework, and lab details.
- Update the LinkedIn links in `index.html` to point to your profile.
- Replace the sample laboratory photographs with images that reflect your work.
